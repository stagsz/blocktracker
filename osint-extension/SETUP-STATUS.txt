🚀 QUICK START:

1. Load Extension in Chrome:
   → chrome://extensions/
   → Enable "Developer mode"
   → Click "Load unpacked"
   → Select: D:\osint-2.1.1\osint-extension

2. Generate Prompt:
   → Click extension icon
   → "New Prompt"
   → Select intelligence type
   → Configure areas
   → Generate

3. Send to AI:
   → Click any AI button (Claude, ChatGPT, Perplexity, Gemini)
   → Prompt copies to clipboard
   → New tab opens with AI provider
   → Paste prompt (Ctrl+V)
